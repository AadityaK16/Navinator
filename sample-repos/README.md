# Sample repos

Small Python projects for trying RepoNav on something other than the demo. Each one shows up in the repo picker. Any folder you add here appears too, as long as its name is lowercase letters, digits, and dashes.

- `todo-api`: a FastAPI todo service with sign-up, login, and a `CurrentUser` dependency.
- `shop-checkout`: a cart priced with discounts, tax, and shipping, then charged and emailed.
- `weather-cli`: a command-line forecast with a file cache and unit conversion.
